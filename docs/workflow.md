# 워크숍 진행 과정

## 1. 공통 작업환경 구축

Notion의 “공통 작업환경 구축” 안내를 사용합니다. 상위 작업 폴더 생성 → Git 설치 → uv 설치 → Antigravity IDE 설치·실행 → git clone → 프로젝트 열기 순서입니다. 이어서 프로젝트 루트에서 `uv init --python 3.12` → `uv venv` → 가상환경 활성화를 진행합니다. 명령은 README의 “시작하기”를 따릅니다.

완료 기준: 프로젝트를 IDE에서 열고, 활성화한 가상환경에서 Python 3.12를 실행할 수 있습니다.

## 2. 예제 데이터 준비

README에 따라 `src/00.get_images.py`를 실행합니다. 각 클래스에서 내용 중복을 제외한 학습 200장·시험 50장을 생성합니다. 실제 폴더와 manifest를 확인합니다.

## 3. Teachable Machine 학습·판독

1. [Teachable Machine](https://teachablemachine.withgoogle.com/)에서 이미지 프로젝트를 엽니다.
2. 클래스명을 `Parasitized`, `Uninfected`로 지정합니다.
3. `dataset/teachable_machine/train/`의 클래스별 이미지만 업로드해 학습합니다.
4. `test/` 이미지를 입력해 실제·예측 라벨을 기록합니다. 시험 이미지를 학습에 넣지 않습니다.
5. 시험한 이미지 수와 선택 기준을 기록합니다. 일부만 판독했다면 전체 시험 세트 성능으로 보고하지 않습니다.
6. 모델을 내보낸다면 로컬 다운로드 결과를 `models/teachable_machine/`에 저장합니다.

## 4. 첫 결과 해석

`results.md`에 혼동행렬, 정확도, 재현율, 정밀도, 특이도를 기록하고 오분류 이미지를 살펴봅니다.

## 5. 로컬 코딩 에이전트 실습

`agent-prompts.md`를 한 단계씩 사용합니다. 전처리 → 모델 생성 → 실제 학습 → 평가 → export 순서로 코드를 작성하고 실행 결과를 확인합니다.

TM 시험 이미지는 공통 시험 세트로 고정합니다. 로컬 학습·검증에는 같은 내용의 파일을 넣지 않습니다. 나머지 이미지에서 학습·검증을 분리하고 모든 비교 모델에 같은 분할을 사용합니다. 데이터 증강은 분할 후 학습 세트에만 적용합니다.

## 6. 비교·마무리

같은 시험 이미지에서 TM과 로컬 모델을 비교합니다. export 모델의 재로드 예측을 확인하고 산출물, 환경, 한계와 개선점을 기록합니다. 이미지 단위 평가를 환자 단위 외부 검증으로 해석하지 않습니다.
