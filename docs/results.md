## 혼동행렬 (감염 = 양성)

| 실제 / 예측 | 감염 | 비감염 |
| --- | --- | --- |

| 비감염 | FP = | TN = |

- 정확도 = (TP + TN) / 전체
- 재현율(민감도) = TP / (TP + FN)
- 정밀도 = TP / (TP + FP)
- 특이도 = TN / (TN + FP)

분모가 0이면 계산 불가로 기록합니다.
