# 로컬 코딩 에이전트 프롬프트

한 단계씩 요청하고 코드·실행 결과를 확인합니다. 오류는 실행 명령과 메시지를 함께 전달해 수정합니다. 경로는 코드 파일 위치를 기준으로 처리하도록 요청하세요.

## 1. 전처리

> README와 dataset/teachable_machine/manifest.csv를 읽고 src/01.preprocess.py를 만들어줘. dataset/raw 아래에서 이미지 파일만 읽고 클래스별 개수를 출력해줘. TM test 이미지를 공통 시험 세트로 고정하고 같은 SHA-256의 모든 파일을 학습·검증에서 제외해줘. 나머지 고유 이미지를 클래스별로 학습 80%, 검증 20%로 나누고 시드 2025를 사용해줘. 다른 라벨에 같은 내용이 있으면 중단해줘. 분할 목록은 dataset/splits.csv, 이미지 격자는 output/samples.png에 저장해줘. 세트 간 내용 중복을 검사하고 개수를 출력해줘. 입력 크기·RGB 변환·정규화 방식을 명시하고 원본은 보존해줘. 아직 학습하지 마.

확인: 고정 시험 세트, 중복 없음, 클래스별 개수, 원본 보존.

## 2. 모델 생성·학습

> src/02.train.py를 만들어줘. splits.csv를 사용해 TensorFlow CNN을 생성하고 실제 model.fit으로 학습해줘. CPU용 작은 모델, 입력 96×96, 기본 5 epoch로 시작하고 표본 수·epoch를 옵션으로 바꿀 수 있게 해줘. Parasitized=1, Uninfected=0으로 sigmoid 출력은 감염 확률로 통일해줘. 시험 세트를 학습·튜닝에 사용하지 마. 데이터 증강은 학습에만 적용하고 추론에서도 동일한 전처리를 재현해줘. 모델은 models/cnn.keras, 이력·곡선·시간·실행 설정은 output/cnn/에 저장해줘. 필요한 라이브러리를 알려주고 실행 후 실제 epoch 로그와 산출물을 확인해줘.

확인: 실제 학습 로그, 가중치 파일, 학습·검증 곡선, 시험 데이터 미사용.

## 3. 평가

> src/03.evaluate.py를 만들어줘. 저장 모델을 다시 읽고 고정 시험 세트만 평가해줘. 감염을 양성으로, 임계값 기본 0.5로 하여 TP/FN/FP/TN, 정확도·재현율·정밀도·특이도·ROC AUC를 계산해줘. 분모가 0이거나 AUC를 정의할 수 없으면 이유를 기록해줘. 실제 라벨·감염 확률·예측 라벨 CSV, 축과 클래스 순서를 명시한 혼동행렬, 오분류 이미지를 output/cnn/에 저장해줘. 실행 전 성능 수치를 추측하지 마.

확인: CSV·혼동행렬 개수 일치, 양성 클래스, 평가 표본 수.

## 4. Export

> src/04.export.py를 만들어줘. 모델과 labels.json, 입력 크기·RGB·정규화·임계값을 담은 preprocessing.json을 models/export/에 저장해줘. Keras 저장 형식과 배포용 export 형식의 목적을 설명하고 필요한 형식을 선택해줘. export 결과를 다시 불러와 동일한 시험 이미지 예측을 원 모델과 비교하고 허용 오차와 결과를 output/에 기록해줘.

확인: 재로드, 클래스 매핑·입력 규격, 예측 비교.

## 5. 선택: 전이학습

> 같은 splits.csv와 시험 세트로 MobileNetV2 전이학습을 구현해줘. ImageNet 가중치, 모델 전용 전처리, 고정 기반층을 사용해줘. 기존 결과를 덮어쓰지 말고 별도 저장해줘. 동일 시험 이미지에서 TM·CNN·전이학습을 비교하고 학습 데이터 수·전처리·시간의 차이도 기록해줘.
