# 로컬 코딩 에이전트 프롬프트

프롬프트는 첫 줄에 목적을 한 문장으로, 그 아래에 세부 조건을 한 문장씩 목록으로 적었습니다. 한 단계씩 요청하고 코드·실행 결과를 확인합니다. 오류는 실행 명령과 메시지를 함께 전달해 수정합니다. 경로는 코드 파일 위치를 기준으로 처리하도록 요청하세요.

## 1. 전처리

```markdown
학습 전에 이미지를 확인하고 학습·검증·시험 세트로 나누는 전처리 스크립트 src/01.preprocess.py를 만들어줘.
- 먼저 README와 dataset/teachable_machine/manifest.csv를 읽고 작업을 시작한다.
- 입력은 dataset/raw 아래에 있는 이미지 파일만 사용한다.
- 클래스별 이미지 개수를 세어 출력한다.
- Teachable Machine의 test 이미지를 공통 시험 세트로 고정한다.
- 시험 이미지와 SHA-256이 같은 파일은 모두 학습·검증 세트에서 제외한다.
- 나머지 고유 이미지는 클래스별로 학습 80%, 검증 20%로 나누고, 시드는 2025로 고정한다.
- 내용이 같은 이미지에 서로 다른 라벨이 붙어 있으면 처리를 중단하고 알린다.
- 분할 목록은 dataset/splits.csv에, 이미지 격자는 output/samples.png에 저장한다.
- 세트 사이에 내용이 겹치는 이미지가 있는지 검사하고, 그 개수를 출력한다.
- 입력 크기, RGB 변환, 정규화 방식을 코드와 출력에 명시한다.
- 원본은 읽기 전용으로 보존해야 한다.
- 전처리만 수행하고 절대 학습단계로 진행하지 않는다.
```

확인: 고정 시험 세트, 중복 없음, 클래스별 개수, 원본 보존.

## 2. 모델 생성·학습

```markdown
감염·비감염 세포를 분류하는 작은 CNN을 만들어 실제로 학습하는 src/02.train.py를 만들어줘.
- 데이터는 dataset/splits.csv에 기록된 분할을 그대로 사용한다.
- 모델은 CPU에서도 실습 시간 안에 학습되는 작은 TensorFlow CNN으로 만들고, 입력 크기는 96×96으로 한다.
- 실제로 model.fit을 실행해 학습하며, 기본 epoch는 5로 한다.
- 표본 수와 epoch는 실행 옵션으로 바꿀 수 있게 한다.
- 라벨은 Parasitized를 1, Uninfected를 0으로 정한다.
- 출력층은 sigmoid로 하고, 출력값은 감염 확률로 해석한다.
- 시험 세트는 학습이나 하이퍼파라미터 조정에 사용하지 않는다.
- 데이터 증강은 학습 세트에만 적용한다.
- 추론할 때도 학습 때와 같은 전처리를 그대로 적용한다.
- 모델은 models/cnn.keras에 저장하고, 학습 이력·곡선·소요 시간·실행 설정은 output/cnn/에 저장한다.
- 설치가 필요한 라이브러리가 있으면 먼저 알린다.
- 실행한 뒤 실제 epoch 로그와 저장된 산출물을 확인해 보여준다.
```

확인: 실제 학습 로그, 가중치 파일, 학습·검증 곡선, 시험 데이터 미사용.

## 3. 평가

```markdown
저장한 모델을 고정 시험 세트로 평가하는 src/03.evaluate.py를 만들어줘.
- 저장된 모델 파일을 다시 불러와서 평가한다.
- 평가는 고정 시험 세트에서만 한다.
- 양성 클래스는 감염(Parasitized)으로 하고, 임계값은 기본 0.5로 한다.
- TP·FN·FP·TN을 세고, 정확도·재현율·정밀도·특이도·ROC AUC를 계산한다.
- 분모가 0이거나 AUC를 정의할 수 없으면 값을 채우지 말고 그 이유를 기록한다.
- 이미지별 실제 라벨, 감염 확률, 예측 라벨을 CSV로 output/cnn/에 저장한다.
- 혼동행렬은 축(실제·예측)과 클래스 순서를 표시해 output/cnn/에 저장한다.
- 잘못 분류된 이미지를 모아 output/cnn/에 저장한다.
- 실행하기 전에 성능 수치를 추측해서 말하지 않는다.
```

확인: CSV·혼동행렬 개수 일치, 양성 클래스, 평가 표본 수.

## 4. Export

```markdown
학습한 모델을 다른 환경에서도 같은 기준으로 쓸 수 있게 내보내는 src/04.export.py를 만들어줘.
- 모델과 클래스 순서를 담은 labels.json을 models/export/에 저장한다.
- 입력 크기, RGB 변환, 정규화, 임계값을 담은 preprocessing.json을 models/export/에 저장한다.
- Keras 저장 형식과 배포용 export 형식이 각각 무엇을 위한 것인지 설명하고, 필요한 형식을 골라 사용한다.
- 내보낸 모델을 다시 불러와, 같은 시험 이미지에 대한 예측이 원래 모델과 같은지 비교한다.
- 비교에 쓴 허용 오차와 비교 결과를 output/에 기록한다.
```

확인: 재로드, 클래스 매핑·입력 규격, 예측 비교.

## 5. 선택: 전이학습

```markdown
같은 조건에서 MobileNetV2 전이학습 모델을 만들어 기존 결과와 비교하는 src/05.train_transfer.py를 만들어줘.
- ImageNet 가중치를 사용하고, MobileNetV2 전용 전처리를 적용하며, 기반층은 고정한다.
- 데이터는 앞 단계와 같은 dataset/splits.csv와 시험 세트를 사용한다.
- 기존 CNN 결과는 덮어쓰지 않고 별도 위치에 저장한다.
- 같은 시험 이미지로 Teachable Machine, CNN, 전이학습 모델의 결과를 비교한다.
- 세 방법의 학습 데이터 수, 전처리, 학습 시간 차이도 함께 기록한다.
```
